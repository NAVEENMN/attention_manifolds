How does this work?

Each selected layer applies a scale to its learned query and key spline deviations. At α = 1, it uses the trained curves. At α = 0, it returns to calibrated identity curves. In Custom, unselected layers use trained curves. Llama bypasses all spline transformations. Identity splines are available by setting all BSpline scales to 0.

Each prompt runs independently, just like the command-line demo. Previous answers are shown for comparison but are not sent to the model. Every answer records its settings.

How this works

Each transformer block in Llama contains Query (Q) and Key (K) linear projections that control how tokens attend to each other. This system wraps each Q/K projection with a learned cubic B-spline curve — one curve per coordinate. The original linear weights remain frozen; only the spline coefficients are trained.

Selecting a layer and changing its α value directly edits how information flows through that transformer block. At α = 1, the trained spline curves are active. At α = 0, the layer reverts to its original linear projection. At α = −1, the learned curve is negated — reversing what the spline learned for that layer.

Each layer's spline operates independently, enabling surgical control over which layers contribute safety behaviour. Layers L0, L9, and L13 carry the strongest safety signals. Editing just one of these layers can flip the model between refusing and complying — demonstrating that safety behaviour in transformers is localised and controllable at the attention level.

Research note

This is a research preview. The interventions shown here have been validated on a landscape sweep of 540 prompts across 13 alpha values (7,020 generations) and per-layer sensitivity analysis on 270 safety prompts across all 28 layers. Behaviour changes are not guaranteed for all prompts — some prompts sit far from the decision boundary and require multi-layer interventions to flip. Results may also vary slightly across GPU architectures and software versions due to floating-point differences in model inference.
