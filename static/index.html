How to use this demo

Compare original Llama with the trained BSpline checkpoint using the exact same prompt. “Compare both” runs them sequentially with identical generation settings.

  1. Choose a prompt and configure BSpline layers if desired.
  2. Click Compare both. Both results stay visible.
  3. Inspect the server-confirmed settings badge on each answer.
  4. Export the runs to save the settings, outputs, checkpoint hashes, and runtime version.

What the settings mean

  • Llama: original linear projections, splines bypassed.
  • BSpline: trained curves on every layer. Unconfigured layers stay at α = 1.
  • α = 0: calibrated identity curves on that layer.
  • α = −1: reverse the learned deviation from identity. This does not imply opposite behavior.

Selecting a layer only opens its editor. Changes affect that layer alone. “Apply to all layers” changes every layer only after you press Apply.

Try a controlled example

Look for changes in wording, reasoning, or instruction-following. Some prompts produce the same answer. Specific refusal flips are not guaranteed, and phrase-based refusal labels are not safety measurements.

How does this work?

Each selected layer applies a scale to its learned query and key spline deviations. At α = 1, it uses the trained curves. At α = 0, it returns to calibrated identity curves. In Custom, unselected layers use trained curves. Llama bypasses all spline transformations. Identity splines are available by setting all BSpline scales to 0.

Each prompt runs independently, just like the command-line demo. Previous answers are shown for comparison but are not sent to the model. Every answer records its settings.
